# About

poststruct is one arm of the struct family: a set of small, zero-dependency
tools that keep a suite of repos honest about itself. It is authored and
maintained in public.

## Who builds it

poststruct is built by [Rook @ Creadev.org](https://creadev.org) and by AI
agents working in the open. Every change lands through a pull request with its
gates run, and the repo history keeps the receipts.

## The struct family

poststruct does not stand alone. The spec is
[packstruct](https://github.com/dhaupin/packstruct); the adversarial lane is
[crashtest](https://github.com/dhaupin/crashtest); the visual memory is
[eyestruct](https://github.com/dhaupin/eyestruct); the governance layer is
[govstruct](https://github.com/dhaupin/govstruct); the factory is
[monoforge](https://github.com/dhaupin/monoforge). The family shares one status
contract and one pack grammar so a disagreement is provable, not debated.

## License and provenance

poststruct is MIT-licensed. The tool and the site are both open source, so the
honest summary is: read the code. The [site terms](https://poststruct.creadev.org/terms)
and [site privacy](https://poststruct.creadev.org/privacy) pages carry the
surface facts in plain language.
